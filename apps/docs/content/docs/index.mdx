Elegant Stack is a Bun-first monorepo template designed to feel production-ready without becoming heavy.

## What ships by default

<Cards>
  <Card title="Web" href="http://localhost:3000" icon="MonitorSmartphone">
    TanStack Start with HeroUI for the main product surface.
  </Card>
  <Card title="Docs" href="/docs/getting-started" icon="BookOpenText">
    Fumadocs running on TanStack Start for structured product docs.
  </Card>
  <Card title="Desktop" icon="LaptopMinimalCheck">
    Electron + SolidJS with a small IPC bridge example.
  </Card>
  <Card title="API" href="http://localhost:3002/health" icon="ServerCog">
    Hono + Drizzle with Bun SQLite for local zero-config development.
  </Card>
</Cards>

## Shared principles

- Bun manages installs and scripts.
- Turbo coordinates dev, build, lint, typecheck, and test tasks.
- Biome keeps formatting and linting consistent.
- UnoCSS provides lightweight utilities and icon support.
- Tailwind CSS 4 stays in the React apps where HeroUI and Fumadocs require it.
