---

## Install dependencies

```bash
bun install
```

## Start the whole workspace

```bash
bun run dev
```

## Or run an individual app

```bash
bun run dev:web
bun run dev:docs
bun run dev:desktop
bun run dev:api
```

## Validate the workspace

```bash
bun run lint
bun run typecheck
bun run test
bun run build
```

## Database helpers

```bash
bun run db:generate
bun run db:migrate
bun run db:studio
```
