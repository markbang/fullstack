## Application map

| App | Purpose | Notes |
| --- | --- | --- |
| `apps/web` | main product shell | TanStack Start + HeroUI |
| `apps/docs` | documentation site | Fumadocs on TanStack Start |
| `apps/desktop` | native desktop shell | Electron + SolidJS |
| `apps/api` | HTTP backend | Hono + Drizzle + Bun SQLite |

## Shared tooling

- `packages/typescript-config/*` centralizes TypeScript baselines.
- `packages/uno-config` shares UnoCSS presets, theme tokens, and shortcuts.
- `packages/design-tokens` holds the reusable visual token layer.
- `packages/shared` holds workspace metadata and cross-app runtime helpers.
- `packages/ui-react` holds reusable React presentation primitives for `web` and `docs`.
- `packages/contracts` holds API-facing DTO and response contracts.
- Root `biome.json` keeps formatting and linting rules in one place.
- Root `turbo.json` defines the task graph for the full workspace.

## Design choice

This template intentionally favors **small shared primitives** over large internal packages.
That keeps the repo easy to understand on day one, while still leaving room to extract shared packages later.
